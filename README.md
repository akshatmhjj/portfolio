# Akshat Mahajan – Portfolio

Personal portfolio at [akshatmajan.in](https://akshatmajan.in).

- `/` – About, experience, education, skills and certifications
- `/work` – Projects, each with a case study page at `/work/<slug>`

## Stack

Next.js (App Router), React, TypeScript, Once UI components, MDX for project pages.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Content

- Personal details, experience, skills and certifications: `src/resources/content.tsx`
- Site settings, routes and SEO: `src/resources/once-ui.config.ts`
- Projects: add an `.mdx` file in `src/app/work/projects/`
