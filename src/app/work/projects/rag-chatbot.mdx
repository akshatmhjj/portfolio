## Overview

Grounded is a retrieval-augmented document chatbot that runs entirely on the local machine. It uses Ollama for local generation and embeddings, ChromaDB for vector storage, and Streamlit for the browser interface, with no API keys or cloud calls involved.

The system is built to avoid confident answers the documents don't support, using source citations, a two-stage refusal strategy, and an evaluation harness that scores retrieval and generation separately.

## What I Worked On

* Built the end-to-end RAG pipeline covering document loading, chunking, embedding, vector search, and grounded generation.
* Implemented heading-aware chunking for markdown and per-page PDF ingestion so citations carry the source file and page.
* Designed a two-guard refusal strategy using a cosine-similarity threshold before the LLM call and a grounding prompt with an exact refusal sentence.
* Built an evaluation harness measuring retrieval hit rate, answer fact rate, and refusal accuracy as independent metrics.
* Achieved 100% retrieval hit rate, 90% answer fact rate, and 92.9% refusal accuracy on a 14-question set including unanswerable questions.
* Tuned the similarity threshold and chunking strategy by comparing logged evaluation runs.
* Added structured JSONL logging of answers, refusal stage, similarity scores, retrieved chunks, token usage, and settings.
* Built a Streamlit interface with live retrieval controls, a retrieved-chunk inspector, in-app index rebuilding, and a query log.
* Isolated configuration and model access behind single modules so switching to a hosted LLM provider requires only configuration changes.

## Technical Stack

* Python for the RAG pipeline
* Ollama with llama3.2 and nomic-embed-text for local generation and embeddings
* ChromaDB for persistent vector storage and cosine similarity search
* OpenAI-compatible client as the single model interface
* pypdf for PDF text extraction
* Streamlit for the browser interface
* JSONL structured logging for queries and evaluation runs

## Outcome

The project demonstrates a measurable approach to RAG quality, with grounded answers, explicit refusal handling, and evaluation that separates retrieval failures from generation failures. Its isolated configuration and model layer allow the same evaluation harness to compare larger local or hosted models without changes to the pipeline.
