## Overview

Code Journey is a free, role-based map for tech careers. Pick a role and see exactly which skills it needs, in what order, with the best official docs and free resources for each one. No courses, no paywalls. Code Journey curates, it doesn't teach.

The platform is built on Next.js (App Router) and TypeScript, with Supabase (Postgres + pgvector) for data and search, and a Gemini-powered AI assistant that answers questions using retrieval-augmented generation over the site's own content.

## Key Features

- **Role maps** - 10 launch roles (Frontend, Backend, Full-Stack, Cross-platform Mobile, Data Analyst, Data Scientist, AI Engineer, ML Engineer, DevOps, QA/SDET), each broken into ordered skills linking to official docs and free resources.
- **CJ AI** - a retrieval-augmented chatbot grounded entirely in the site's own content (900+ indexed passages), using hybrid vector and keyword search, with streamed, cited answers.
- **Personal dashboard** - signed-in users can save roles, track skill progress (to do, learning, done), and see remaining stages and estimated hours.
- **Compass quiz** - a short quiz that ranks roles by fit for the user's interests and background.
- **Gap checker** - compares a user's existing skills against any role's requirements, matched entirely in the browser.
- **Role comparison** - side-by-side skill overlap between any two roles.
- **Public profiles** - an opt-in, shareable progress page at /u/[handle].
- **Four visual themes** - Juniper, Harbor, Tangerine, and Orchard, each with light and dark modes.
- **Installable PWA** - works offline for previously visited pages.

## Technical Stack

- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS
- **AI:** Google Gemini (generation + embeddings), retrieval-augmented generation, hybrid pgvector + tsvector search
- **Database & Auth:** Supabase (PostgreSQL, pgvector), Google and GitHub OAuth
- **Infrastructure:** Vercel, Cloudflare DNS
- **Version Control:** Git, GitHub

## Outcome

Code Journey is live at codejourney.space as a free, curated map for tech careers. No account is needed to browse any role map; the personal layer (saved progress, quiz, gap checker, public profile) is opt-in for users who sign in. The whole map currently covers 10 roles and about 100 individual skills, with more roles planned.
